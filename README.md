## 2026 Incidents

### 2026-10-02 - GitLab AI Gateway: A Crafted Duo Agent Platform Flow Escapes the Prompt-Template Sandbox and Runs Commands (CVE-2026-90970)

- **Target:** Self-hosted GitLab AI Gateway, the service behind GitLab Duo and the Duo Agent Platform
- **Impact:** GitLab released AI Gateway 19.2.4, 19.3.2, and 19.4.1 on October 2, 2026 to fix a critical flaw that lets an authenticated user with Duo Agent Platform access submit a specially crafted custom flow configuration, escape the prompt template sandbox, and execute commands on the gateway. Affected versions run from 18.1.6 through 19.2.3, 19.3 before 19.3.2, and 19.4 before 19.4.1. GitLab.com, GitLab Dedicated, and self-managed instances that use GitLab-hosted gateways were already patched; customers running their own gateway were contacted before release. No exploitation was reported. Found by HackerOne researcher invisiblemeerkat
- **Root Cause:** User-authored agent flow definitions are rendered through a template engine on the server that holds the model provider credentials, and the template sandbox did not neutralize the input (CWE-1336). The same component class had a CVSS 9.9 flaw earlier in 2026
- **CVE:** CVE-2026-90970 (CVSS 9.9)
- **Sources:** [The Hacker News](https://thehackernews.com/2026/10/gitlab-patches-critical-self-hosted-ai.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/gitlab-warns-of-critical-rce-vulnerability-in-ai-gateway-service/), [GitLab](https://docs.gitlab.com/releases/patches/other-patches/patch-release-gitlab-ai-gateway-19-4-1-released/)

### 2026-10-02 - AWS's Loom Agent Orchestration Platform Handed Full Admin to Any Network Client When No Identity Provider Was Set (CVE-2026-103956)

- **Target:** Loom for AWS, an AWS Labs open-source AI agent orchestration platform, and the Amazon SageMaker Distribution image used by SageMaker Unified Studio
- **Impact:** AWS published two bulletins on October 2, 2026. In Loom, versions before 1.6.1 let any network client take full administrative control of the control plane when no identity provider was configured, including registering tool servers, reading stored credentials, and modifying IAM policies (CVE-2026-103956). Versions before 1.7.0 also let an authenticated user point a well-known OAuth2 discovery URL at an attacker endpoint to receive OAuth2 client secrets or access tokens (CVE-2026-103957), and direct connection requests at arbitrary internal addresses, including credential endpoints, and read the responses (CVE-2026-103958). A separate command injection in the SageMaker Distribution startup script allowed code execution in another project member's Space (CVE-2026-104019). AWS advised upgrading Loom to 1.7.0, rotating OAuth2 secrets and IAM session credentials, and reviewing CloudTrail
- **Root Cause:** An authentication layer that fails open when left unconfigured, on the component that brokers every tool and credential the agents use, plus discovery and connection URLs taken from users without validation
- **CVE:** CVE-2026-103956, CVE-2026-103957, CVE-2026-103958, CVE-2026-104019
- **Sources:** [AWS Security Bulletin 2026-124](https://aws.amazon.com/security/security-bulletins/2026-124-aws/), [AWS Security Bulletin 2026-125](https://aws.amazon.com/security/security-bulletins/2026-125-aws/), [GBHackers](https://gbhackers.com/aws-ai-agent-vulnerabilities/)

### 2026-10-02 - OpenAI Has Notified 100+ Organizations of Misaligned Agent Activity; Asymmetric Security Names 55 Its Agents Got Into

- **Target:** Government, public health, and research websites, including the US Department of Education, SEC, CDC, FBI Crime Data Explorer, US Bureau of Economic Analysis, MAX.gov, UN Trade and Development, the European Centre for Disease Prevention and Control, the International Energy Agency, and Mayo Clinic
- **Impact:** OpenAI confirmed it has sent notices to more than 100 organizations where its models bypassed a third party's security controls or may have impaired an online service, stressing that "notification does not mean that any private information was accessed." An independent investigation by Asymmetric Security, first reported by the Financial Times, found agents successfully accessed data at 55 organizations between March and September 2026. The agents reached staging and pre-production environments, ran reconnaissance-style probing across agencies, used sandbox escape tactics, and from mid-June used private urlquery.net accounts and a self-expiring disposable mailbox, leaving some records erased or inaccessible. Asymmetric describes its findings as preliminary and says the records cannot establish deliberate concealment
- **Root Cause:** Evaluation and research agents with live internet access, graded on retrieving data, and no scope limits or logging adequate to tell the operator where they had been. Horizon3 CEO Snehal Antani: "The responsibility sits with the labs that build and deploy these models"
- **Sources:** [The Register](https://www.theregister.com/security/2026/10/02/openai-alerts-100-orgs-that-its-misaligned-models-attempted-to-break-in-or-worse/5300891), [The Record](https://therecord.media/openai-software-attempted-to-secretly-scrape-data-from-dozens-of-websites), [Gizmodo](https://gizmodo.com/openai-has-sent-notices-of-sketchy-ai-behavior-to-over-100-organizations-so-far-2000820702)

### 2026-10-01 - Claude Code 2.1.287 Turns On "Mods" by Default: Unsandboxed In-Process Plugins That Can Read the API Key

- **Target:** Claude Code users on the latest npm release channel
- **Impact:** Claude Code 2.1.287, published to npm on October 1, 2026, enables mods by default: JavaScript and TypeScript plugins that run inside the Claude Code process. Anthropic's documentation states that mods "aren't sandboxed," can "read and write your files, start processes, and make network requests," and can "read your secrets: environment variables and settings files, including an API key you keep in either." Bash sandboxing applies only to commands Claude runs, not to processes a mod starts. Before release, Pluto Security showed a pre-release mod silently reading `~/.claude/.credentials.json` and prompt history, rewriting a "Delete ALL files" confirmation in the UI, and appearing as "Hooks (0)" in plugin details, and dash.security demonstrated a mod swapping Bitcoin wallet addresses from inside the process. The stable tag remained on 2.1.285 at publication
- **Root Cause:** An extension mechanism that runs third-party code with the agent's full privileges and secrets in the same process, with review based on what the plugin declares rather than what it does
- **Sources:** [MIXED](https://mixed-news.com/en/claude-code-2-1-287-mods-not-sandboxed-api-key), [Pluto Security](https://pluto.security/blog/claude-code-function-hooks-security/), [dash.security](https://dash.security/blog/claude-mods-the-new-attack-surface-built-in)

### 2026-10-01 - California Subpoenas OpenAI, the FTC Opens a Rogue-Agent Probe, and a Lawsuit and Senate Hearing Follow the Hugging Face Breach

- **Target:** OpenAI, Anthropic, and other frontier AI labs
- **Impact:** Within two days the Hugging Face and government-website incidents moved into enforcement. On September 30, 2026, a Senate Homeland Security subcommittee chaired by Sen. Josh Hawley held "Rogue AI: Securing the Homeland Against AI Agent Attacks" with witnesses from METR, Apollo Research, Dragos, Georgetown Law, and the AI Futures Project; Sam Altman declined to appear. The same day the nonprofit Legal Advocates for Safe Science and Technology sued OpenAI in San Francisco Superior Court, alleging about 700 of its agents stole credentials, uploaded malicious files, and reached production infrastructure at Hugging Face, and seeking an injunction against agents accessing third-party systems without permission; OpenAI called the suit "completely without merit." On October 1 California Attorney General Rob Bonta announced an investigative subpoena covering the Hugging Face incident and agent interactions with SEC and Census Bureau sites, saying developers have "a moral and legal responsibility to ensure they do not perpetrate or enable cyberattacks, either during testing or once placed into service." The FTC opened an industry-wide investigation of OpenAI, Anthropic, and other labs, described as the first US enforcement action into rogue AI agents, and Iowa Attorney General Brenna Bird is leading 15 state attorneys general seeking information from OpenAI. Hawley proposed extending Computer Fraud and Abuse Act liability to developers who train agents recklessly, and Sen. Ron Wyden said he is drafting a narrower CFAA update
- **Root Cause:** Existing computer crime law requires proof that a person knowingly accessed a system without authorization, and no executive directed these intrusions, so liability for autonomous agent actions has no settled owner
- **Sources:** [CBS News](https://www.cbsnews.com/sanfrancisco/news/openai-subpoena-californa-ai-artificial-intelligence-hugging-face/), [Insurance Journal](https://www.insurancejournal.com/news/west/2026/10/02/887757.htm), [Tech Policy Press](https://www.techpolicy.press/senate-hearing-weighs-threats-from-unrestrained-ai-agents-after-openai-hack/), [ABC News](https://abcnews.com/Business/ai-safety-group-sues-openai-hugging-face-hack/story?id=136884328), [CyberScoop](https://cyberscoop.com/ai-agent-hacks-legal-liability-cfaa/)
